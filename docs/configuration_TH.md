# การตั้งค่าและคำศัพท์

[English](configuration.md) · **ภาษาไทย** · กลับไป [README](../README_TH.md)

## การตั้งค่า
เปลี่ยนค่าได้ในแผง Settings ค่าที่ตั้งจะถูกบันทึกในเบราว์เซอร์

| การตั้งค่า | ค่าเริ่มต้น | ช่วงที่ตั้งได้ |
|---|---|---|
| ระยะเวลาโฟกัส (นาที) | 25 | 1–90 |
| พักสั้น (นาที) | 5 | 1–30 |
| พักยาว (นาที) | 15 | 1–60 |
| รอบก่อนพักยาว (จำนวนรอบโฟกัส) | 4 | 1–12 |
| เป้าหมายโฟกัสต่อวัน (นาที) | 120 | 1–1440 |

## ที่เก็บข้อมูลในเบราว์เซอร์
ข้อมูลทั้งหมดอยู่ใน `localStorage` ของเบราว์เซอร์ คีย์ขึ้นต้นด้วย `cp_` เช่น

- `cp_theme`: ธีมที่เลือก
- `cp_streak`: streak ปัจจุบัน
- `cp_tasks`, `cp_mission_boards`: รายการภารกิจ
- `cp_session_history`: ประวัติรอบการโฟกัส

การล้างข้อมูลของเว็บไซต์จะรีเซ็ตแอป ควรกดส่งออกข้อมูลก่อนเสมอถ้าต้องการเก็บสำรอง

## คำศัพท์
| คำ | ความหมาย |
|---|---|
| รอบโฟกัส | ช่วงทำงานหนึ่งช่วงของตัวจับเวลา |
| รอบก่อนพักยาว | จำนวนรอบโฟกัสก่อนจะถึงการพักยาว |
| Streak | จำนวนวันติดต่อกันที่มีการโฟกัสอย่างน้อยหนึ่งรอบ |
| บอร์ดภารกิจ | รายการงานที่มีชื่อกำกับ |
